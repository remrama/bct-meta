# Measuring mindfulness with the Breath Counting Task: a meta-analysis

Data and code for a meta-analysis of the Breath Counting Task (BCT; Levinson et al., 2014)
as a behavioural measure of mindfulness. Two questions:

1. **Sensitivity to training** — does BCT accuracy increase after a mindfulness intervention,
   relative to control conditions? (`code/meta_prepost.R`)
2. **Convergent validity** — how strongly does BCT accuracy correlate with self-reported
   mindfulness, psychological wellbeing, and executive function? (`code/meta_corr.R`)

> Status: analysis pipeline complete on the 2021 extraction set; a systematic literature
> search to update the study set is in progress. Numbers below will change.

## Reproduce

From the repository root:

```sh
Rscript -e "renv::restore()"   # once: installs the package versions pinned in renv.lock
Rscript code/run_all.R         # ~10 s; writes every result and figure to derivatives/
```

R package versions are pinned with [renv](https://rstudio.github.io/renv/) (`renv.lock`, recorded
under R 4.6.1). Starting R in the repository root activates the project library through
`.Rprofile`. If renv itself is missing, that step installs it. `run_all.R` refuses to run if renv
isn't active, so results never come from unpinned packages. Inside the scripts, paths resolve
through `here::here()`, which finds the root by the empty `.here` file. This works without a
`.git` directory, e.g. from a release archive.

The Python helpers (`code/digitize_*.py`) are not part of the pipeline. They are managed with
[uv](https://docs.astral.sh/uv/): `uv run code/digitize_levinson2014.py` creates the environment
from `uv.lock` on first run.

## Layout

```
sourcedata/                   hand-curated inputs; never written by code
  breathpubs_corr.xlsx        raw extraction: correlations (one row per reported r)
  breathpubs_prepost.xlsx     raw extraction: pre/post means (one row per arm)
  scales_corr.xlsx            acronym -> instrument lookup for correlates
  publications.csv            every publication in the sheets with full title and DOI
  zotero_import_dois.txt      the DOIs, one per line, for Zotero "Add by Identifier"
  codebook.json               column definitions for the sheets above
  *_digitized.csv, *_plot.*   plot-digitizer output + source figure for two studies
code/
  load_data.R                 reads the sheets, assigns IDs, applies inclusion rules, writes derivatives/exclusions.csv
  meta_prepost.R              pre/post analysis + Figure 1
  meta_corr.R                 correlation analysis + Figure 2
  run_all.R                   runs the three scripts and records sessionInfo()
  digitize_*.py               converts digitized points to means/SDs (one-off; values already in the xlsx)
derivatives/                  everything generated by code (tracked, except figures)
```

## Analysis summary

**Inclusion.** BCT only (MBAS/MBE rows in the sheets are retained but excluded; see
`derivatives/exclusions.csv` for every excluded row and why).

**Pre/post.** Standardized mean change with raw-score (pre-test SD) standardization
(`metafor` measure `SMCR`, Hedges-corrected). No study reports the pre/post correlation, so
*r* = 0.5 is assumed (sensitivity: 0.3, 0.7; `derivatives/prepost_sensitivity_r.csv`). The
headline estimate is the controlled effect — intervention-arm change minus control-arm change
within each study (Becker, 1988) — pooled with a REML random-effects model. Levinson et al.
(2014) had two control arms (n-back, no training); they are pooled into one. Leave-one-out and
Egger's test are in `derivatives/`.

**Correlations.** Fisher-*z* transformed. Because samples contribute several correlations, each
construct is fitted with a three-level random-effects model (effects nested in samples) and
cluster-robust standard errors; sensitivity analysis aggregates to one effect per sample ×
construct (within-sample ρ = 0.5). Signs are flipped where needed so that positive *r* means
higher BCT accuracy goes with more mindfulness / better wellbeing / better executive function.

## Outputs (`derivatives/`)

Figures (PNG and PDF) aren't committed. Run the pipeline to create them.

| File | Content |
|---|---|
| `fig_prepost_forest.{png,pdf}` | Figure 1: within-arm changes and controlled effects |
| `fig_corr_forest.{png,pdf}` | Figure 2: correlations by construct |
| `figS_*_funnel.{png,pdf}` | funnel plots |
| `prepost_effects_arms.csv`, `prepost_effects_controlled.csv` | per-study effect sizes |

| `exclusions.csv` | every excluded sheet row with the reason |
| `session_info.txt` | R and package versions of the last run |
