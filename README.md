# Measuring mindfulness with the Breath Counting Task: a meta-analysis

Data and code for a meta-analysis of the Breath Counting Task (BCT; Levinson et al., 2014)
as a behavioural measure of mindfulness. Two questions:

1. **Sensitivity to training** — does BCT accuracy increase after a mindfulness intervention,
   relative to control conditions? (`code/meta_prepost.R`)
2. **Convergent validity** — how strongly does BCT accuracy correlate with self-reported
   mindfulness, psychological wellbeing, and executive function? (`code/meta_corr.R`)

> Status: analysis pipeline complete on the 2021 extraction set; a systematic literature
> search to update the study set is in progress. Numbers below will change.

## Reproduce

```sh
Rscript code/run_all.R   # ~10 s; regenerates everything in results/
```

Requires R ≥ 4.1. The script installs any missing packages (`metafor`, `dplyr`, `tidyr`,
`readxl`, `here`, `ragg`) on first run.
Paths resolve from the repository root via `here::here()` (which finds the `.git` directory), so
the scripts run from any working directory.

```
  load_data.R                 reads the sheets, assigns IDs, applies inclusion rules, writes results/exclusions.csv

```

## Analysis summary

**Inclusion.** BCT only (MBAS/MBE rows in the sheets are retained but excluded; see
`results/exclusions.csv` for every excluded row and why).

**Pre/post.** Standardized mean change with raw-score (pre-test SD) standardization
(`metafor` measure `SMCR`, Hedges-corrected). No study reports the pre/post correlation, so
*r* = 0.5 is assumed (sensitivity: 0.3, 0.7; `results/prepost_sensitivity_r.csv`). The
headline estimate is the controlled effect — intervention-arm change minus control-arm change
within each study (Becker, 1988) — pooled with a REML random-effects model. Levinson et al.
(2014) had two control arms (n-back, no training); they are pooled into one. Leave-one-out and
Egger's test are in `results/`.

**Correlations.** Fisher-*z* transformed. Because samples contribute several correlations, each
construct is fitted with a three-level random-effects model (effects nested in samples) and
cluster-robust standard errors; sensitivity analysis aggregates to one effect per sample ×
construct (within-sample ρ = 0.5). Signs are flipped where needed so that positive *r* means
higher BCT accuracy goes with more mindfulness / better wellbeing / better executive function.
